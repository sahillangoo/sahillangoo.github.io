## Overview

Designed and engineered for UK-based professional photographer and Director of Photography **Rooh Yaseen** (Wolf of Watford documentary, Apple TV, broadcast filmography). The site adheres to a strict editorial "Less, But Better" design ethos, focusing 100% of user attention on high-resolution motion reels and photographic narratives.

## Technical Innovations

- **Facade Video Loading Pattern**: High-resolution video embeds and showreels load lightweight image facades initially; heavy video players (`<iframe>`) load asynchronously only upon explicit user interaction, saving over 4MB of initial payload.
- **Obsidian Dark Color Space**: Bespoke OKLCH color token architecture (`#0A0A0B` obsidian canvas, crisp `#F4F4F5` foreground typography, stone/zinc borders).
- **Lenis Smooth Scroll Synchronization**: Flawless page transitions, hardware-accelerated momentum scrolling, and scroll position retention across dynamic filter categories.
- **Zero Cumulative Layout Shift (CLS = 0.00)**: Strict aspect-ratio containers ensuring imagery never shifts page layout during render.
