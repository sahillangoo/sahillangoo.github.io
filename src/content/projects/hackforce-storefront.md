## Overview

HackerForce is a static web platform providing cybersecurity intelligence reports, course catalog management, and tactical product listings with offline-capable full-text search.

## Features

- **Pagefind Search Integration**: Zero-server static search indexing embedded during build.
- **Tactical Purple Metal Design**: Curated 60:30:10 visual design system adhering to strict WCAG accessibility guidelines.
