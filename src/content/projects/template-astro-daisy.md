## Overview

An open-source starter repository created to help developers bootstrap ultra-fast websites with Astro, Tailwind CSS, and daisyUI components without configuring tooling from scratch.

## Stack & Best Practices

- Pre-configured with ESLint 10 Flat Config and Prettier Astro plugins.
- Built-in theme switching (dark/light) using semantic daisyUI tokens.
